# BondStats Financial Centre Clock Widget v5

Professional homepage edition based on the original Global Financial Clock.

Includes:
- Tokyo
- Singapore
- Hong Kong
- London
- New York
- analog and digital live clocks
- local date
- IANA time zones / automatic DST
- core-hours status
- true single-column mobile layout

Mobile fix:
This build has NO hard-coded minimum document width. It uses the smallest available iframe/device/visual viewport signal and all mobile cards are width:100% with only a 66px clock column plus a flexible minmax(0,1fr) content column.
